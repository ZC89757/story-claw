## 启动顺序

1. `gpu_config.json` 为托管模式时，查询并启动明确指定的现有实例；容量不足在 `start_timeout` 内重试。
2. 云实例开机后由服务器已有进程管理器启动原生 ComfyUI。仓库的 H3 专用部署脚本是 `scripts/setup_autostart.sh`、`scripts/start-h3-service.sh`，不再启动 LTX wrapper。
3. 读取 `/object_info`，核验实际节点、模型和必填输入。
4. 实际生成最短合法 H3 视频：124 帧、24 fps、保留 0.4 MP 分辨率与音视频 VAE 链，仅将采样步数降为 1。
5. 下载原生视频，核验帧数、帧率并完整解码。成功才进入正式生成；error 状态不放行。
6. 主流水线无论成功失败，都在 finally 中关闭托管实例。

`scripts/grab_gpu.py` 兼容入口现在转调主项目 TS 生命周期。桌面设置和配置示例仅展示 H3 参数。外部模式仍明确表示不代管云实例，保存密钥不会覆盖这一选择。
