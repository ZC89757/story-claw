# Story Claw 产品截图

Story Claw 是一款将小说章节自动转化为短剧内容的 AI 工具，帮助创作者完成文稿处理、分镜制作、配音和视频渲染。

下面的截图来自 Story Claw 当前可运行版本，用于展示主要操作界面和功能流程。

## 1. 产品首页

![Story Claw 产品首页](./story-claw-home.png)

首页用于输入或上传小说章节。用户可以选择自动人物风格和完整制作模式，然后创建项目。

**功能作用：** 让用户从一段小说文字开始，进入后续的剧本、分镜和视频制作流程。

## 2. 集工作台

![Story Claw 集工作台](./story-claw-episode.png)

集工作台展示当前集的分镜列表、画面预览、总时长和生成进度。用户可以查看每个分镜，也可以重新生成画面或继续制作成片。

**功能作用：** 集中管理一集短剧的分镜内容，方便检查画面效果和制作状态。

## 3. 项目确认

![Story Claw 项目确认](./story-claw-business-confirmation.png)

项目确认页面用于确认正式项目名称和后续制作配置，在开始批量生成内容前锁定项目基础信息。

**功能作用：** 避免项目名称、制作目标和配置在流水线运行过程中发生混淆。

## 4. 制作流水线

![Story Claw 制作流水线](./story-claw-pipeline-start.png)

制作流水线展示从素材整理、画面预设、资源建档、分镜制作，到 GPU 渲染和成片输出的阶段进度。

**功能作用：** 把复杂的短剧制作拆成清晰的步骤，便于查看当前阶段，并在中断后继续执行。
